# まいにち理科ノート

小学生のための理科クイズです。中学受験に出るような問題が、毎日 10 問ずつ出ます。

- **学年ごとの 4 つのレベル**: 3 年生むけ / 4 年生むけ / 5 年生むけ / 6 年生むけ
- **16 の分野**: 毎日ちがう 10 分野から 1 問ずつ出ます。分野は日ごとに順に回り、8 日間でどの分野もちょうど 5 問。生物・地学・化学・物理の 4 つの系統は、毎日かならず入ります
  - 生物: 植物 / 動物 / 人体 (骨と筋肉・消化・血液・目・耳・神経) / 環境 (食物連鎖・数のつり合い・外来種・地球温暖化)
  - 地学: 天体 (太陽・月・星・惑星) / 気象 / 大地 (流れる水・地層・岩石・火山・地震・自然災害と防災)
  - 化学: 物質 (水溶液・気体・燃焼・中和) / 熱 (体積の変化・三態・熱量の計算)
  - 物理: 電球の明るさ / 電磁石・発熱 / てこ・輪軸 / かっ車 / ばね・浮力 (水圧・密度) / ふりこ・運動 / 光・音
- **どの分野も全学年に**: 3・4 年生むけは身近な現象や用語、5・6 年生むけは計算やグラフ、と難しさを変えています
- **実験器具の使い方**: 器具を使う単元の分野に入っています (`src/questions/tools.ts`)。
  3・4 年生むけは虫めがね・しゃ光板 (光・音)、温度計・アルコールランプ (熱)、検流計 (電球の明るさ)。
  5・6 年生むけはけんび鏡 (植物・動物)、メスシリンダー・上皿てんびん・ガスバーナー・気体検知管・リトマス紙 (物質)、電流計 (電磁石・発熱)。
  温度計・メスシリンダー・電流計は、目もりを図から読む問題もあります
- **自然災害と防災**: 大地の分野に入っています。4 年生むけは大雨のときの川・ハザードマップ・ひなん、
  5 年生むけは洪水とそれをふせぐしくみ (さぼうダム・てい防・ゆう水地)、5・6 年生むけはハザードマップの図を読む問題、
  6 年生むけは液状化・津波・土しゃ災害と、緊急地震速報からゆれがとどくまでの時間の計算です
- **同じ日は同じ問題**: 日本時間の日付とレベルから乱数の種を作るので、いつ・どの端末で開いても同じ 10 問になります。日付が変わると新しい問題になります
- **図つき**: 回路図、てこ、かっ車、月の形などの図は、問題の数値に合わせてその場で SVG としてかきます (画像ファイルは使いません)
- **スタンプカードと柴犬カード**: 10 問をとき終えるとスタンプとポイントがもらえ、ためたポイントで柴犬のカード (20 種類) と交換できます
- スマートフォン・タブレット・PC のどれでも使えます。暗い画面の設定では、黒板のような色になります
- とちゅうの答えと結果は、ブラウザの `localStorage` に保存します。Google でログインすると Firestore にも保存され、ほかのブラウザや端末でも同じ記録でつづけられます (ログインは任意)

## スタンプ・ポイント・柴犬カード

[Wordlynx](../wordlynx/) のスタンプカードとヤマネコカードと同じ仕組みです。キャラクターは柴犬です。

| もらえるとき | ポイント |
|---|---|
| 10 問をとき終える (学年ごと・1 日 1 回) | 20pt |
| その 10 問が全問正解 | さらに 10pt |
| スタンプが 7 日つづくたび | 1,000pt |
| その月の 1 日から末日まで、スタンプが全部そろう | 5,000pt |

- **スタンプ**は 1 日 1 個。どれかの学年の 10 問をとき終えた日に押されます (いくつの学年をといても 1 個)
- スタンプもポイントも、保存してある「とき終えた日と正解数」から毎回計算します (`src/core/rewards.ts`)。合計を別に保存しないので、ずれたり二重にもらったりしません。
  この機能ができる前にとき終えていた日も、そのままスタンプとポイントになります
- **柴犬カード**は 20 種類・合計 28,420pt (`src/data/cards.ts`)。値段のならびはヤマネコカードと同じです。まだ持っていないカードは裏向きで、値段だけが見えます
- 柴犬の絵とカードの絵柄は `src/ui/shiba.ts` で SVG としてかいています。開発サーバーの `cards.html` で、全部のデザインを一覧できます (ビルドには入りません)
- ログイン中は、持っているカードも Firestore に保存されます (`inventory`)。スタンプは `activeDays` に入ります

## Google のタグ

ビルドのときに、環境変数 `GTM_ID`、なければプロジェクト直下の `config.js` (`config.example.js` を参照) の `GTM_ID` を読んで、
`index.html` に Google のタグを埋めこみます。どちらもなければ埋めこみません。`config.js` は Git で管理しません。

GitHub Pages に公開するときは、リポジトリの変数 `GTM_ID` に ID を入れてください (`.github/workflows/deploy.yml`)。

## ログインと記録の保存 (Firebase)

[Wordlynx](../wordlynx/) と同じ仕組み・同じ Firebase プロジェクトを使います。
Google でログインした人の記録は Firestore に保存し、ログインしない人は今までどおりそのブラウザの localStorage だけに保存します。
**Firebase の設定を入れていないビルドでは、ログインの入り口は出ず、Firebase のコードも読みこまれません。**

- 画面はいつも手元 (localStorage) の記録を読み書きする (`src/core/storage.ts`)
- ログイン中は、手元の記録を「Firestore の写し」としてあつかい、書きかわった分を少しまとめてから Firestore に送る (`src/cloud/sync.ts`)
- ログインしたとき・ページを開いたときは、Firestore の記録と手元の写しを合わせて、両方に書く。
  合わせ方は `src/core/merge.ts` にあり、何回合わせても同じ結果になる

  | 記録 | 合わせ方 |
  |---|---|
  | とき終えた日と正解数 | 両方を合わせる。同じ日・同じ学年が両方にあれば、正解数の多いほう |
  | その日の途中経過 | 先まで答えているほう。同じところまでなら、あとから保存したほう |
  | 持っている柴犬カード | 両方を合わせる (同じカードは払った額の小さいほう) |

- 手元の記録は人ごとに分ける。ログインなしの記録は `science-quiz:v1:…`、ログイン中の人の写しは `science-quiz:u:<uid>:…`。
  ログアウトすると、その人の写しは端末から消す (きょうだいで 1 台を使っても、記録がまざらない)
- ログインしたとき、その端末にログインなしの記録があれば、アカウントにうつすかどうかを聞く
- 通信できないときも手元の写しで使え、つながったときに送る

### Firestore の形

Wordlynx と同じ形 (小学生向けの学習アプリで共通) で、`appId` だけがちがいます。Wordlynx の記録とはまざりません。
ルールも Wordlynx と同じ (`firestore.rules`。読み書きできるのはログインしている本人だけ) なので、**ルールを入れ直す必要はありません。**

```
users/{uid}                                        その人の情報 (全アプリ共通)。名前・メールアドレスは保存しない
users/{uid}/apps/science-quiz                      記録のまとめ
  activeDays: string[]                             どれかの学年の 10 問をとき終えた日
  completed:  string[]                             とき終えた「レベル:日付」(g3:2026-10-12 など)
  settings:   { scores: { "g3:2026-10-12": 8 } }   正解数
  inventory:  { s01: { paid: 40 } }                持っている柴犬カードと、交換に使ったポイント
  spent: {}                                        (このアプリでは使わない)
users/{uid}/apps/science-quiz/progress/{日付:レベル}  その日の途中経過 (前の日までのものは消す)
  status: "playing" | "done"
  data: { sig, answers }                           問題の印と、えらんだ答え
```

### 設定

Wordlynx と同じ 4 つの値を入れます。4 つのうち一部だけを入れると、ビルドがエラーになります。

- 手元: `config.js` に `FIREBASE_API_KEY` `FIREBASE_AUTH_DOMAIN` `FIREBASE_PROJECT_ID` `FIREBASE_APP_ID` を書く (書き方は `GTM_ID` と同じ)
- GitHub Pages: リポジトリの Settings → Secrets and variables → Actions → Variables に、同じ 4 つの名前で登録する
- 公開先のドメインが Wordlynx とちがうときは、Firebase コンソールの Authentication → 設定 → 承認済みドメイン に足す

ログインに失敗すると、ボタンの下に Firebase のエラーの名前 (`auth/unauthorized-domain` など) が出ます。
原因と直し方は Wordlynx の README の「ログインできないとき」と同じです。

### エミュレーターで動かす (開発用)

本物の Firebase を使わずに、手元でログインと保存をためせます (Java が必要)。

```sh
npx firebase-tools emulators:start --only auth,firestore --project demo-science-quiz
FIREBASE_API_KEY=x FIREBASE_AUTH_DOMAIN=localhost FIREBASE_PROJECT_ID=demo-science-quiz FIREBASE_APP_ID=x FIREBASE_EMULATOR=1 npm run dev
```

エミュレーターには Google のログイン画面がないので、ブラウザのコンソールで `window.__testUser = 'kid1'` としてからログインのボタンをおします。

### 問題を足すには

`src/questions/` の分野のファイルにジェネレーターを足し、ファイルの最後の一覧に、出す学年といっしょに入れます
(`forGrades(lowerExample, 3, 4)` なら 3 年生むけと 4 年生むけ)。どの学年も、分野ごとに 2 つ以上のジェネレーターが必要です。
ほかの分野のファイルにあるジェネレーターを `import` して、一覧に入れることもできます (人体の一覧は、動物のファイルの消化や血液の問題を使っています)。

```ts
const lowerExample: Gen = {
  id: 'plants-l-example', // ほかと重ならない名前
  make: (rng) =>
    choice(rng, {
      text: '問題文',
      correct: '正解',
      wrong: ['まちがい1', 'まちがい2', 'まちがい3'],
      explanation: '解説',
    }),
};
```

- 乱数は、わたされた `rng` だけを使います (`Math.random()` を使うと、同じ日に同じ問題になりません)
- 知識を問う問題をまとめて足すなら `facts()`、数で答える問題なら `numeric()` が使えます (`src/questions/helpers.ts`)
- ジェネレーターを足したり中身を変えたりすると、その日の問題も変わることがあります
