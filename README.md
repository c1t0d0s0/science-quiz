# まいにち理科ノート

小学生のための理科クイズです。中学受験に出るような問題が、毎日 10 問ずつ出ます。

- **2 つのレベル**: 3・4 年生むけ / 5・6 年生むけ
- **7 つの分野**: 植物・動物・天体・物質・電球の明るさ・てこ・輪軸・かっ車。毎日どの分野からも 1 問以上出て、のこりの 3 問は日ごとに順に回ります (7 日間でどの分野もちょうど 10 問)
- **同じ日は同じ問題**: 日本時間の日付とレベルから乱数の種を作るので、いつ・どの端末で開いても同じ 10 問になります。日付が変わると新しい問題になります
- **図つき**: 回路図、てこ、かっ車、月の形などの図は、問題の数値に合わせてその場で SVG としてかきます (画像ファイルは使いません)
- スマートフォン・タブレット・PC のどれでも使えます。暗い画面の設定では、黒板のような色になります
- とちゅうの答えと結果は、ブラウザの `localStorage` に保存します (サーバーには送りません)

## 動かし方

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に公開用のファイルを作る
npm run preview  # dist/ の中身を手元で見る
```

開発サーバーでは `gallery.html` で、全部のジェネレーターが作る問題を図といっしょに見られます
(`?n=3` で見本の数、`?level=upper` でレベル、`?only=lever` で分野、`?figs=1` で図だけ)。ビルドには入りません。

## Google のタグ

ビルドのときに、環境変数 `GTM_ID`、なければプロジェクト直下の `config.js` (`config.example.js` を参照) の `GTM_ID` を読んで、
`index.html` に Google のタグを埋めこみます。どちらもなければ埋めこみません。`config.js` は Git で管理しません。

GitHub Pages に公開するときは、リポジトリの変数 `GTM_ID` に ID を入れてください (`.github/workflows/deploy.yml`)。

## しくみ

| 場所 | 中身 |
|---|---|
| `src/core/daily.ts` | その日の 10 問を組み立てる (分野の割りふり、乱数の種) |
| `src/questions/*.ts` | 分野ごとの問題ジェネレーター。`lower` が 3・4 年むけ、`upper` が 5・6 年むけ |
| `src/questions/ruby.ts` | 3・4 年むけの問題につける、ふりがなの一覧 |
| `src/diagrams/*.ts` | 図 (SVG) をかく関数 |
| `src/ui/*.ts` | ホーム・問題・結果の画面 |
| `tests/` | 400 日分の出題の確認と、計算問題の検算 |

### 問題を足すには

`src/questions/` の分野のファイルにジェネレーターを足し、ファイルの最後の一覧 (`lower` か `upper`) に入れます。

```ts
const lowerExample: Gen = {
  id: 'plants-l-example', // ほかと重ならない名前
  make: (rng) =>
    choice(rng, {
      text: '問題文',
      correct: '正解',
      wrong: ['まちがい1', 'まちがい2', 'まちがい3'],
      explanation: '解説',
    }),
};
```

- 乱数は、わたされた `rng` だけを使います (`Math.random()` を使うと、同じ日に同じ問題になりません)
- 知識を問う問題をまとめて足すなら `facts()`、数で答える問題なら `numeric()` が使えます (`src/questions/helpers.ts`)
- ジェネレーターを足したり中身を変えたりすると、その日の問題も変わることがあります
